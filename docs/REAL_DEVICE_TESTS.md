# 真实手机琴房验收记录模板

状态：未实测。现有连接设备为Android15模拟器；它只能验证AudioRecord调用与页面生命周期，不能证明手机钢琴识别准确率。原始录音默认不保存；需要留样时先取得用户同意，再明确本地位置与删除方式。

每次记录：日期、App SHA/版本、手机品牌型号/Android版本、输入设备与采集源、琴型、摆放距离、房间条件、权限与系统麦克风开关、测试谱版本/人工真值、校准版本。音频延迟需要已知基准和统一时钟，未取得时填未测。

| 场景 | 当前状态 | 后续需记录 |
| --- | --- | --- |
| 单音、音阶 | 未实测 | 人工音符真值、识别结果、错判/漏判、延迟 |
| 双音、三和弦、四音和弦 | 未实现识别，未实测 | 音符集合准确率与每音符漏检 |
| 左右手简单 / 快速演奏 | 未实现识别，未实测 | 定位偏差、错判、恢复时间 |
| 延音踏板、弱音、强音 | 未实测 | 起音与旧音混淆、削波、低置信度 |
| 快速重复音、停顿后继续 | 仅合成PCM回归 | 真实重复起音检出、恢复时间 |
| 故意弹错、故意漏音 | 未实现正式判定 | 错误检出、漏判、False Stop Rate |

False Stop Rate = 人工确认弹对却发生错误锁定的次数 / 可评价的正确演奏事件数。当前无正式锁定引擎，不能填0%冒充低误停。准确率、错判率、漏判率与恢复时间也不能从静音采集测试推导。

每阶段开始实现前在对应TEST_MATRIX文件固定样本版本、样本数与阈值，不能测完后降低门槛；本表只保留未取得的实测条件，不伪造数据。
