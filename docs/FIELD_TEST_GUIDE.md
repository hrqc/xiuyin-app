# 手机实地测试指南

适用版本：0.3.0-octave.2-fieldtest.1（versionCode 6）。这是诊断闭环测试版；物理手机琴房识别、误停率与端到端延迟尚未验证。安装包最终身份、真实检测状态以本版交付清单为准。

## 安装与准备

1. 将交付的 APK 复制到 Android 8.0 / API 26 或以上手机，在文件管理器点击安装；系统询问时只允许此次使用的文件管理器安装。如果已安装同签名版本，可覆盖安装保留数据；不卸载、不清除应用数据。若提示签名冲突，先保留旧数据并反馈提示，不强行卸载。
2. 打开 App，进入“曲库 → 导入与数字乐谱”，导入本机谱图、PDF、MusicXML 或 MIDI，也可选择已有数字乐谱。图片识谱后先用原图对照校正，避免把谱子识错算作演奏错误。
3. 在乐谱工作台点击“开始陪练”，选择练习方式和小节范围。要复查误停可选“错音即停”；来源警告必须由你校对确认。
4. 进入“设置 → 开发 / 实地测试”，检查显示的是本版、数字乐谱已就绪。给本次测试填写备注，例如钢琴类型、手机型号、离琴距离与房间情况。
5. 等待真实模型状态 READY，再点击“开启实地测试”；首次开始时授予麦克风权限。LOADING 不能开始，失败请查看原因后显式重试。不需要登录或服务器。

## 在单人琴房里使用

把手机稳放在钢琴附近，使用手机自带麦克风，不连接耳机或蓝牙。先做少量单音、重复音、真实八度和弦，再弹选定片段；分别尝试不踩踏板和正常踏板。每段情况写入会话备注，便于以后解释。

练习、环境校准和实地测试页面在前台保持常亮；切到其他 App 或锁屏会停止收音，返回后需手动继续。不要在后台弹完再回来，后台没有采集证据。常亮不改变系统息屏设置。

遇到系统误判，尽快点“我弹对了”；自己确实弹错时点“这里确实弹错了”。两种按钮只留下不同的待复核标签，不自动解锁、不移动指针，也不把标签当作准确率真值。若已锁停，可正常重弹目标音尝试恢复；不确定的八度会显示 AMBIGUOUS_OCTAVE / UNCERTAIN，仍须结合原始输出复核。

若同意保存短片段，开启“我同意异常或反馈时保存前 3 秒、后 1.5 秒的短音频到本机”。默认不保存整段录音；不勾选也能记文字反馈和模型证据。请在事件后尽快标记；片段已离开最多 5 秒内存范围时会如实记录无法保存。暂停/退出时后半段可能不足，ZIP 会标明实际范围。

如出现模型失败、Queue Overflow、麦克风异常或诊断写入失败，App 会暂停。不要继续依赖当前判断；先结束并导出已有会话，恢复条件后另开新会话。

## 一键导出并交回

1. 在实地测试页点击“结束实地测试会话”。
2. 在该会话卡片点击“一键导出此会话 ZIP”，等到显示 ZIP 已生成。
3. 点“保存 ZIP 到文件”，在 Android 文件选择器中选本机 Download / 下载等位置，确认保存。App 会读回校验 SHA-256；看到“已保存并通过 SHA256 读回校验”才算保存成功。也可主动选择“分享测试 ZIP”，由你选择接收应用；App 无法证明外部应用已接收，请在接收端核实。
4. 将刚结束的这次会话对应的完整 `field-<sessionId>.zip` 发给 Codex，附上手机型号、琴房情况和你觉得异常的时间段。不要只发 APK、截图或单个 app.log，也不要重新压缩或改写包里的文件。

每个 ZIP 包含版本和设备信息、运行日志、真实模型 88 键输出、八度证据、跟谱前后位置及锁停原因、性能/队列记录、用户反馈和已授权短片段。它不包含整段原始录音。App 意外退出后重新打开，在历史会话中选择 INCOMPLETE 的上次会话导出，缺失的尾段不会伪造补齐。若曲库数据库出现错误，仍可从“设置 → 开发 / 实地测试”导出已有诊断；这时正式收音会被禁止。

本地默认总预算为 200 MiB、300 个片段、20 次会话。总预算包含导出 ZIP 的预留空间，因此可能在当前文件占用尚未到 200 MiB 时暂停记录，目的是让你仍能结束并导出；只自动清理已经确认导出的旧会话，不静默删未导出记录。确认 ZIP 已另存后可点该会话“清理”，再次确认才删除本地副本。

## 已知边界与回退

旧 DotIAM 第二组仍是未通过音乐验收的数据，不能以新增歧义保护宣称八度误检已解决。高精度 OMR、真人踏板/混响、手机差异仍要实测；未知指标会保持 null / 未验证。

上一稳定版本是 `v0.2.0`，上一个八度基线检查点是 `v0.3.0-octave.1`。不要在手机上自行清库或卸载降级。需要回退时保留导出 ZIP 与曲库，按 `docs/ROLLBACK.md` 对已有保存产物及数据兼容性检查后执行；本轮模拟器回退的实际结论见最终交付清单。
