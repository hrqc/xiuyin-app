### 这次为什么卡住

截图里的 11 项是 9 个小节缺拍号和 2 处反复顺序待确认，发生在练习开始前，不是判你弹错了 11 次。照片是续页，没有印出拍号；程序需要这个信息检查每小节时值。你导出的旧日志显示，之后修订到第 7 版，已经开始练习。

后来目标 D5 停留约 94 秒，是另一问题。你确认争议时弹 D5，模型却多次保留 D5/D6 歧义，跟谱长期等待 UNCERTAIN。它不是缺拍号，也不能归咎于你节拍不对；本轮音乐失败结论保留。

### 覆盖安装和准备谱面

1. 收到本版正式交付 APK 后，用 Android 8.0/API26 以上手机的文件管理器覆盖安装。保留原 App 和曲库，不卸载、不清数据；签名冲突时保留提示并反馈。

### 开始记录、换手和反馈

1. 从工作台点“开始陪练”，再进入“实地测试与导出”。核对谱名、修订、模式和手别。双谱表可选择右手、左手或双手，先慢速自由跟弹；需要指定小节范围时，先在陪练页选好并实际开始，再进入实地页沿用配置。

4. 等模型显示 READY，再点“开启实地测试”，允许麦克风。确认 FIELD TEST MODE 和麦克风 LISTENING 后再弹。未 READY、谱面/存储/麦克风有错时不要绕过提示；加载好不会自动开麦。

7. 前台练习、校准和实地测试保持常亮；切后台或切换谱面页面会停止收音，回来后手动继续。遇模型、麦克风、Queue Overflow 或写日志错误，暂停测试，先保存已有证据。

### 一键导出 ZIP

1. 测完点“结束实地测试会话”。在本次会话下点“一键导出此会话 ZIP”。
2. 等待生成后点“保存 ZIP 到文件”，在系统文件选择器选“下载”等本机位置并保存。长会话压缩和校验可能明显等待，期间不要退出、反复点击或清理。
3. 回 App 看到“测试包已保存并通过 SHA256 读回校验”，才算保存成功。进行中导出的只是当时快照，结束后请重新导出。打开分享窗口不代表文件已交到接收端。
4. 把完整 ZIP 交回来，附实际弹的音/段落、踏板、左右手和异常时间。不改包内文件，不只给截图。

### 弹奏、暂停与换手

自己弹对但App判断错，尽快点**我弹对了**；自己确实弹错点**这里确实弹错了**。它们只保存待复核标签，不自动解锁、不移动指针，也不代表准确率真值。锁停后可按提示重弹目标，但当前D4八度歧义仍可能不能恢复。

可留在实地测试页对照纸谱练习。点**查看实时陪练谱面**会暂停收音；到谱面页等READY后点**继续陪练**。返回Field同样暂停，需点**继续现场收音**。切到后台或锁屏也停止收音，返回后手动继续。练习、校准及实地测试在前台保持屏幕常亮，不修改系统息屏设置。

休息时点“暂停现场收音”。更换手或模式前，先结束并导出Field会话，再点“查看实时陪练谱面”；若还有**结束并保存报告**按钮，点它并等待结束，之后回“实地测试与导出”选择新手、新备注、新会话。只结束Field日志会话，原练习可能仍暂停，页面会沿用旧配置。

模型、麦克风、Queue Overflow或诊断写入错误会暂停当前测试。先结束并导出已有记录，再按提示恢复并新建会话，不把异常中断的数据写成通过。

### 下一次专门记录D4误判

你确认反复D4的新视频中，真实回放有3次D4起音附近多接受3次D5。**视频开始已经LOCKED，首次锁停没有原生Field日志**，所以下次必须从创建新会话开始留证。

1. 结束并导出旧Field、结束旧练习。导入单独的 `d4-repeat-field-reference.musicxml`，核对TEST DATA名称，打开工作台，再“开始陪练 → 实地测试与导出”。
2. 选“错音即停”、保留“双手”，备注写**D4单音／不踏板**；愿意提供异常片段时勾选同意项。此谱单谱表不分左右手，实际只弹D4。
3. 等READY，开启Field，确认LISTENING和目标**D4（MIDI62）**后再弹。无需先弹C4，App没有另外的“D4测试模式”。
4. 不踩踏板，每次按下后松开D4，间隔约2秒再弹。多认D5、歧义或锁停时立即点**我弹对了**；确实按错则点另一种反馈。保持同一会话记录，尽量不切页面。反馈不会清锁。
5. 结束会话并按下节导出ZIP，附实际按键、踏板情况和异常次数。此步骤用于补齐诊断，不预先承诺识别通过。

## 安装与准备

1. 将交付的 APK 复制到 Android 8.0 / API 26 或以上手机，在文件管理器点击安装；系统询问时只允许此次使用的文件管理器安装。如果已安装同签名版本，可覆盖安装保留数据；不卸载、不清除应用数据。若提示签名冲突，先保留旧数据并反馈提示，不强行卸载。
2. 打开 App，进入“曲库 → 导入与数字乐谱”，导入本机谱图、PDF、MusicXML 或 MIDI，也可选择已有数字乐谱。图片识谱后先用原图对照校正，避免把谱子识错算作演奏错误。
3. 在乐谱工作台点击“开始陪练”。选择“错音即停”等练习方式，填写“起始小节”和“结束小节（空为全曲）”；有来源警告时先校对并勾选确认。等待模型 READY，再点击“开始实时陪练”，首次按提示授予麦克风权限。确认状态栏显示“监听跟谱”及所选方式后，先不要弹琴。只选择选项而不点击开始，设置不会传入本次陪练。
4. 点击底部“设置”，这一步会自动暂停陪练并停止收音，保留刚才的练习方式和小节范围；再点“开发 / 实地测试”。检查版本和数字乐谱，填写本次现场备注。不要用系统返回或“结束并保存报告”替代这一步。
5. 等模型重新 READY，再点击“开启实地测试”。此时创建诊断会话并继续刚才的练习设置；确认 FIELD TEST MODE 和麦克风 LISTENING 后再开始弹琴。LOADING 不能开始，失败按提示显式重试；不需要登录或服务器。若未事先启动陪练，直接开启 Field Test 使用默认自由跟弹与全曲范围。

## 在单人琴房里使用

把手机稳放在钢琴附近，使用手机自带麦克风，不连接耳机或蓝牙。先做少量单音、重复音、真实八度和弦，再弹选定片段；分别尝试不踩踏板和正常踏板。现场备注只能在开启会话前填写。若要分别记录每段的条件，可每段新建会话并预先填写备注，或在交回 ZIP 时附文字说明和对应时间段。

练习、环境校准和实地测试页面在前台保持常亮；切到其他 App 或锁屏会停止收音，返回后需手动继续。不要在后台弹完再回来，后台没有采集证据。常亮不改变系统息屏设置。

遇到系统误判，尽快点“我弹对了”；自己确实弹错时点“这里确实弹错了”。两种按钮只留下不同的待复核标签，不自动解锁、不移动指针，也不把标签当作准确率真值。若已锁停，可正常重弹目标音尝试恢复；不确定的八度会显示 AMBIGUOUS_OCTAVE / UNCERTAIN，仍须结合原始输出复核。

若同意保存短片段，开启“我同意异常或反馈时保存前 3 秒、后 1.5 秒的短音频到本机”。默认不保存整段录音；不勾选也能记文字反馈和模型证据。请在事件后尽快标记；片段已离开最多 5 秒内存范围时会如实记录无法保存。暂停/退出时后半段可能不足，ZIP 会标明实际范围。

如出现模型失败、Queue Overflow、麦克风异常或诊断写入失败，App 会暂停。不要继续依赖当前判断；先结束并导出已有会话，恢复条件后另开新会话。

1. 在实地测试页点击“结束实地测试会话”。
2. 在该会话卡片点击“一键导出此会话 ZIP”，等到显示 ZIP 已生成。
