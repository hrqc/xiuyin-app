# 单音与多音识别专项

更新：2026-10-15。用户明确主攻识音；对应 PRODUCT 第 8、9、12 节。点评、评分和 UI 扩展暂不作为本专项目标。

## 验收目标

- 单音：音符与八度正确，少报假高八度，保留弱音、短音及每次重复击键。
- 多音：识别同时发声的完整音集合，分别统计漏音和多音；只识别和弦中的一个音不算通过。
- 真八度与泛音：同时、先后八度分别验证，不直接删除上方音，不借谱面改写声学结果。
- 新起音与余音：保留真实重击，踏板余音不冒充新击键；没有踏板真值的数据不计算踏板准确率。
- UNKNOWN 不计正确。工程测试通过、回归集改善和新真机音乐验收分别报告。
- 当前任务是音符集合识别；不能由 88 键分类结果宣称已验证 Hz 或音分测量精度。

## 当前受控声学基线

DotIAM2：17 组、23 个预期音。固定录音和真实历史 raw88，使用本轮编译的现有生产声学后处理离线重放：接受 30 个音，多检 7，漏检 0。

三套网站录音（Autopiano、旧 DotIAM、DotIAM2）均已用于诊断，属于回归集，不再是未见独立验收集。手机 D4/D5 只有局部用户确认，不能据此给整段音频补造逐音真值。

短音现有最短按键约 160–179 ms；缺更短、弱奏和多音区专门数据。琴房及手机材料缺可靠踏板开关标签。真实八度仍缺多音区、多力度、同时及错时组合。

## 本轮识音生命周期修复

Tracker 显式发布真实待确认候选，安全层只延续已经取得的独立攻击证据。待确认不等于已确认音或物理真值；取消、拒绝、削波和缺帧会清除失效证据。取消后立即重新起音需要合法恢复，不能把较晚达到 frame 门限当成新的起音时间。

原始 88 键分数、接受的 onset/active 集合、模型、阈值和谱面逻辑不作为本轮改动项。本修复不解决现有强泛音假八度，不能宣称单音或多音准确率提高。

扩大未决候选拦截范围的实验已被跨层测试证伪：低音晚取消会丢掉真实高音。因此该实验没有纳入最终实现；原始失败和实验源码保留于 `reports/octave-pending-fix-20261015/rejected-broad-candidate/`。D4 第 252 帧的未决缺口仍保留为待解决问题，未改写为通过。

3. 再比较音色校准或识音模型改进的收益；不以固定阈值、延长确认帧或删除上音替代真实识别能力。
