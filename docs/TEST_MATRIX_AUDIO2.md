# 本地真实钢琴模型测试门槛（推理前固定）

本页只规定可重复测试，不表示已经通过。输入模型不接收目标乐谱。

- 固定模型SHA256：69ac3567d8ee5fda620225a49c62839c3e82165e89d54d1af63caac877605dfc。
- 输入48kHz mono PCM16，无增益；127tap FIR降采样16kHz；输入窗17920样本/1120ms，512ms滑窗，输出32ms帧，重复帧去重。
- 原始frame/onset输出是logits；sigmoid只称激活分数，不称校准概率或准确率。无offset，pedal UNKNOWN。
- 起音候选onset>=0.60且frame>=0.50；后续一帧onset>=0.60或frame>=0.50确认。onset降到<0.35后才重新武装，重复起音至少96ms。持续音低于0.35连续3帧才释放。削波或不连续不能产生可接受新起音。
- 数据队列有界，超载明确ERROR且暂停，不静默丢帧；硬件端到端延迟尚未测量。

## 网站真实钢琴受控输入

来源：用户指定https://www.autopiano.cn/；真实页面音源经可信键盘输入，直接捕获WebAudio PCM，不替换音源。它验证受控网站采样钢琴，不代表实体钢琴/琴房/手机麦克风。

先冻结 expected-timeline.json 和capture-manifest.json及WAV哈希；按每个预期按键时间+MIDI与识别新起音做一对一匹配，时间容差 ±250ms（包含谱窗标记/两帧确认，不事后移动单个事件）。全局固定时差如需要，必须独立报告，不作为原始门槛通过。

- 单音precision与recall分别 >=0.90；任意错音都列明。
- 两个三和弦按完整集合准确匹配，无额外音，2/2；和弦收集容差100ms。
- 五次重复同音检出5次，无额外重击计数。
- 静音窗口没有接受新起音；原始激活和低证据候选保留。
- 所有输出必须有限，时间单调，模型真实SHA匹配；分开报告执行成功与音乐判定是否通过。
- 逐音真值只来自可信键盘/声音记录的这组受控输入，不能用预期乐谱当琴房实录真值。

## 声学歧义保护（第二次识别实现，验收门槛保持不变）

首轮连续网站输入25真实按音全部被检出，但有9个额外低音/八度音，精确率73.53%、两个三和弦未过。这是需修复的真实失败，不把执行成功算作通过。

新增独立PCM声学支持：只检查神经网络已经提出的候选，不由声谱代替模型产生音符，不读取目标谱。用2048样本Hann窗及Goertzel检查候选前3个谐波；全部低于0.00003或最强候选基音幅度的1.5%者标UNCERTAIN。同步起音中，上方八度候选基音低于下方强音的32%时标为谐波歧义UNCERTAIN。原始88维模型输出仍原样保留，另存candidateRejections。

这些参数是保守工程保护，不是校准概率。弱奏的真实八度和弦、基音/前3谐波被环境掩盖的低音可能仍UNCERTAIN；不能宣称所有双手、88键、踏板已经验证。合成回归须同时覆盖真实低音叠高音和强八度和弦不会被一律删除。
第三次识别实现将所有音高统一要求3个连续证据帧（起音候选+后续2帧支持）；两帧即消失的击键宽带瞬态保持UNCERTAIN。比前版多32ms确认延迟。该规则不按特定键位、谱曲或测试预期特判；短音可能未能确认，须单独验证。以上音频、和弦、重复、±250ms验收门槛不变。
## DotIAM 新独立输入与谐波归属保护（Android 最终运行前固定）

原 DotIAM 留出集已用于诊断，现在只算回归，原失败证据保留。新集 `reports/dotiam-piano-independent2-20260921` 在最终模型推理前冻结，17组/23音，包括8个单音、2个三和弦、真实低音八度与五度、5次同音重复。`tools/evaluation/website-corpus.json` 固定原始WAV与独立标签哈希。新集不能用于调参后仍自称独立。

额外通用 PCM 保护：对NN候选检查前6个谐波的窄带峰，独立基音优先；无基音的候选不能仅借用其他有基音音符的谐波通过。宽带瞬态不作确定音。原模型、激活阈值、3帧确认及上述 ±250ms、三和弦100ms、5次重复门槛均不降低。真实弱基音但有独立高次谐波、真实八度与五度纳入单元回归；这是保守工程判据，不代表现场准确率。

每次完整门禁在最终APK内回放 Autopiano 回归和两组 DotIAM：分别验证 FREE 与正确谱 STOP_ON_ERROR 全部目标组完成、0 WRONG、0 MISSED、0误锁；错误参考谱必须出现实际锁停及后续纠正恢复；真实报告持久化往返一致。声学起音另外按独立时间线一对一核对；三和弦/八度/五度必须完整且无额外音，不得以不锁停或UNCERTAIN冒充正确识别。
