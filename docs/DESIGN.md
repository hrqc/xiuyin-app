# V0.1 原生界面与架构

采用 Kotlin + Jetpack Compose + Android SQLite，minSdk 26。第一阶段无后端、无网络权限。缓存依赖版本固定，之后按需求逐版扩展。

视觉按用户要求采用温馨琴房：奶油白 #FAF6EF、暖白纸 #FFFDF8、浅木色 #DFC6A4、杏棕主色 #A65F3F、鼠尾草绿 #5E7057、正文暖棕 #3F352D。中文使用系统 sans，标题清晰而克制；数字和监控用等宽字体。乐谱白纸与琴键几何作为视觉特征，不展示虚构成绩或时长。

导航：首页 / 曲库 / 练习 / 监控。曲库打开乐谱详情，详情进入练习设置。首页显示最近打开。静态原创示例用于页面验收，标 TEST DATA；V0.2 才接入数字谱格式和正式排版。

SQLite 负责最近打开、练习准备设置、真实运行日志。控制器在 IO 线程读写，Compose 只呈现状态。监控为独立页面，展示本进程与数据库状态；未实现引擎和未测指标显示未运行/未测量。App 关闭后不继续监控。
