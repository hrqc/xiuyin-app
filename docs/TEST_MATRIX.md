# V0.1.0 验收矩阵（实现前固定）

需求来源：PRODUCT.md 第 32 节 V0.1。测试集标识：foundation-1。

| 项目 | 必需验证 / 阈值 |
| --- | --- |
| 编译与静态检查 | assembleDebug、assembleRelease、lintDebug 全部成功，Lint 不允许 error/warning |
| 数据单测 | 内置原创示例标识唯一、静态谱完整；准备配置与日志逻辑测试全部成功 |
| SQLite 集成 | 新建、读写、重新打开持久化、非法值拒绝、日志清理全部成功 |
| UI 端到端 | 首页→曲库→乐谱→练习设置保存→监控可打开，无崩溃；返回与 Activity 重建恢复 |
| 能力边界 | 不申请麦克风/相机/网络权限，不生成检测音符/评分；静态示例标 TEST DATA |
| 日志监控 | 实际操作生成日志；搜索/等级筛选/暂停继续/确认清空可用；未实现引擎不得显示正常 |
| 数据恢复 | 重开 App 后最近打开曲目、练习设置保留；日志存数据库 |
| 包检查 | 输出 APK 与校验值；包名 com.xiuyin.app、版本0.1.0；真机支持未实测则标注 |

本版音频采集、音高/多音识别、跟谱、音符正确性、音频延迟、OMR 不适用，均为后续版本；不以页面操作证明算法有效。

实测设备、Android 版本、通过/失败数与日志在每次 reports/<run_id>/ 中保存。测试失败不得打稳定标签或合并 main。没有历史稳定版本时如实记录；本版不宣称完成生产产物自动回退。
