# V0.2.0 验收矩阵（实现前固定）

测试集标识：digital-score-1。基线：v0.1.1 / ef048363759f7ab706b4a08f80d63647a1bccacb。沿用所有音频/原功能回归，不降低阈值。

## 承诺范围

本地未压缩 MusicXML score-partwise 导入 → 确定性 Digital Score → 小节时值与结构疑点 → 原文件本地保存 → 关闭后重新打开与显示真实事件。MusicXML 直接解析，不调用 OMR，不生成假的置信度或 sourceBox。导入界面是数字事件校对视图，完整五线谱排版、简谱、移调、试听、编辑与实时目标联动不在本版范围。

支持边界由解析器显式检查。无法可靠支持的音乐语义拒绝或产生 NEEDS_REVIEW，不能静默补音/替换。文件最多 2 MiB，限制结构深度与事件数；拒绝 DTD/外部实体、压缩 MXL、MIDI、PDF/图片及任意非乐谱 XML。本版不会调用云端提供者或上传乐谱，文件由用户系统选择器主动选择。

## 必需门禁（不允许跳过）

| 检测 | 数据与操作 | 通过阈值 |
| --- | --- | --- |
| 原功能回归 | 既有41项、原曲库/设置/音频/生命周期/日志 | 原有断言保留；全部通过、零跳过 |
| 解析与时序 | 人工构造原创 MusicXML：音高/临时升降、休止、和弦、backup/forward、谱表/声部、拍号/调号 | 与人工参考逐字段相同，和弦不重复推进时间；ID确定且唯一 |
| 安全与异常 | 非XML、畸形XML、DTD实体、超过大小/深度、不支持音乐结构 | 明确失败或疑点；无外部解析、无固定音符替换 |
| 音乐校验 | 足拍、欠拍/超拍、多个声部与不完整属性 | 与预设疑点匹配，不自动改源文件 |
| 存储 | 保存、同源去重、不同文件、新实例重新打开、损坏/容量边界 | 字节及SHA相同；错误可见；不覆盖源文件/原SQLite |
| UI与集成 | 真实ContentResolver本地URI导入、失败恢复、查看事件/疑点、重建后打开 | 正确内容从实际文件解析，未实现能力不显示成功 |
| 构建与静态 | 离线依赖、Kotlin/Java编译、严格Lint、Debug/Release | 全部退出0，无Lint问题 |
| 运行及日志 | Android15/API35模拟器冷启动、系统文件选择器导入/取消、监控日志 | UI可用；最终SHA匹配；当前进程无FATAL EXCEPTION；解析失败记录原因 |
| 回退 | 候选→v0.1.1→候选安装/启动，比较SQLite业务值和新乐谱源文件哈希 | 两版本均启动、旧数据相同、新文件保留且恢复后可再解析 |

每个失败尝试保存独立 run_id；工作区预检通过后才提交，随后在最终固定SHA再次完整检测，通过才创建标签并快进main。

## 不适用与未验证

本版没有后端/API，OMR/音高模型与正式跟谱尚未实现；不能据此宣称其验收通过。手机/钢琴琴房/音高准确率/False Stop Rate/实际音频端到端延迟仍未验证。当前仅Android15模拟器；其他系统版本未验证。复杂MusicXML全集及全部制谱软件兼容性未验证。用户已明确不配置远程，无Push/远程CI。
