| 必需项目 | 真实操作/参考 | 阈值 |
| --- | --- | --- |
| 无名称导入 | 无work-title/movement-title的原创MusicXML实际解析/导入 | originalTitle=null，显示命名提示，音符不变 |
| 临时名称 | 两份不同无名来源、跳过输入、重启/删除后再导入 | 未命名乐谱 001等唯一递增，不因重启计数复用 |

| 多字段搜索 | 自定/原名/alias/tag/文件名/作者/作品号 | 每项命中参考，空查询全量，无网络 |
| 同名 | 两份不同来源均改相同名称 | 两个scoreId不同，编辑/收藏/删除互不影响 |
| 排序与收藏 | 导入时间、已有练习时间（测试输入）、名称、收藏 | 排序参考一致；UI不把打开当练习；无练习时间显示未有 |
