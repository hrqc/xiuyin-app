# v0.3.0 乐谱工作台验收矩阵（实现前固定）

测试集workbench-1。基线v0.2.0/dbe1a852，保留其全部124项回归；本版为完整陪练升级的第一个可运行小版本，不把它命名为完整陪练。

| 检查 | 必须通过的条件 |
| --- | --- |
| 乐谱显示 | 真实DigitalScore驱动五线谱/简谱/双谱，音高、升降、八度、时值、休止、附点、谱表、拍调号与实际事件一致；点击定位稳定eventId；不能拿截图代替渲染 |
| 编辑 | 音高/时值/升降/休止/增加删除/和弦单音/谱表声部/连音线/拍调谱号可改变真实DigitalScore；不支持的表示明确警告；原始来源字节不变 |
| 同源联动 | 修改/移调后渲染与试听共享currentScore，时间线、MIDI音高及稳定ID可断言相同；为后续实时陪练保留同一入口，尚无陪练模型时不可声称其已验收 |
| 修订持久化 | 独立修订文件、原子保存、重启加载、撤销/重做、用户确认与指法随历史恢复；过期generation拒绝，损坏保留并报错，不重建旧数据库 |
| 真实试听 | 根据音符/时值生成本地PCM并经AudioTrack实际输出；停止/后台/离开释放，播放头驱动试听位置；明确合成试听音色，禁止冒充钢琴录音或识音 |
| 移调 | 升降半音、12个目标调；调号、真实音高、简谱和试听同步；边界及异常调号拒绝，不只改文字 |
| 理论校验 | 欠拍/超拍、同声部重叠、无效音高、破损tie等显式报错或待校对；编辑不能吞掉尚未确认来源问题 |
| 实际操作 | 系统选择器导入原创TEST DATA→打开工作台→点音符修改→保存→切换谱式→移调试听→撤销重做→冷启动恢复；检查真实日志 |
| 回归与构建 | 既有124项、新增测试全部通过，0失败/0跳过；严格Lint、Debug/Release、实际启动 |
| 回退 | 候选→归档v0.2.0→候选实际安装/启动；旧SQLite、元数据、源谱与新增修订内容保持；不卸载、不清数据 |

首批视觉与时序参考使用明确原创MusicXML，人为指定音高和时值是测试输入，不称OMR输出。用户两张JPG和琴房视频继续保留给后续OMR/识音验收，不拿本版通过代替最终核心验收。手机扬声器音质、真机麦克风、多音准确率、误停率、复杂雕版完整性、OMR仍未验证或后续实现。旧产品要求全部保留。


## v0.3.0 完整链路增补（对应最终规范，设备总门禁前固定）

保留上表门槛。本轮进一步接入真实本地 OMR/识音/陪练，已实现不等于已验证。

| 集合 | 必须执行与通过条件 |
| --- | --- |
| OMR-1 | 用户两张 JPG 经当前 APK 原生模型全新执行，非缓存；逐 token→Digital Score 保留、sourceBox、装饰音、原图/JSON SHA、二次读取一致；空白输入明确失败；真实逐音准确率无人工真值，保持未验证 |
| companion-1 | 真实网站连续 PCM 回放经过当前识音引擎，与事先记录的独立琴键时间线核对；正确前进、错音暂停、纠正恢复、持续音不重复推进、UNCERTAIN不判错、报告持久化；回放不是现场手机实测 |
| calibration-1 | 5秒RAM环形缓存、退出清空、显式同意才落盘、200项/100MiB上限、参数限定范围、损坏明确报错、反馈不自动解锁；未知环境指标保持空值 |

| MIDI-1 | 真实SMF0/1 PPQ音符时间解析、原始字节留存、独立归档、当前修订导出再读音高/时间一致；SMPTE/type2等未支持输入明确拒绝 |
| 完整操作 | 现有命名/别名/标签/同名UUID/排序、修谱/原图对照/单音及小节恢复/撤销、简谱/移调/试听/实时陪练同源更新全部保留；模拟器实际界面操作、重启和回退数据不丢 |
